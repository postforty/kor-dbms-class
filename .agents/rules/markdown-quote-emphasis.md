# 마크다운 강조 규칙 (따옴표·괄호·인라인 코드와 강조 기호)

따옴표(`'`, `"`), 괄호(`[]`, `()`), 백틱(`` ` ``) 바로 뒤에 한글 조사가 붙으면 강조 기호(`**`, `*`)가 닫히지 않고 그대로 노출되므로 다음 규칙을 준수합니다.

1. **따옴표·괄호**: 기호는 반드시 강조 기호(`**`, `*`) 바깥에 배치합니다.
   - **Do**: `'**결제**'로`, `"**회원가입**"을`, `[**내 바우처함**]에`, `"*안내 메시지*"`라는
   - **Don't**: `**'결제'**로`, `**"회원가입"**을`, `**[내 바우처함]**에`, `*"안내 메시지"*라는`

2. **인라인 코드(백틱)**: `**`로 감싸지 않고 백틱 단독 사용 또는 `<b>` 태그를 사용합니다.
   - **Do**: `` `OR`로 ``, `<b>`OR`</b>로`
   - **Don't**: `**`OR`**로` (❌ `**` 노출), `` `**OR**`로 `` (❌ 코드 내 `**` 노출)
